## 🚀 Projetos em destaque / Featured projects

### 🌱 [Raiz](https://github.com/marcioecom/raiz) — HackaRun 2026
PWA de fidelização para shopping center (UniCatólica & Capim Dourado Shopping) que transforma o QR Code da NFC-e em recorrência e missões entre lojas sem integração com PDV.
- **Minha atuação:** documentação inicial e liderança do Front-end PWA (7 telas responsivas, validação NFC-e módulo 11 + fila offline, cliente HTTP tipado via OpenAPI 3.1, exportação LGPD, simulador mobile e 18 arquivos de teste Vitest).
- **Links:** [Aplicação Live](https://raiz.marcio.run) · [API Docs](https://raiz-api.marcio.run/docs) · [Pitch (90s)](https://youtube.com/shorts/Ny_S21jVItg)

`React 19` `TypeScript` `Vite 7` `TanStack Router/Query` `Tailwind CSS v4` `PWA` `OpenAPI 3.1` `Vitest`

### ⛪ Paróquia em Rede — Projeto Integrador UNITINS *(repositório privado)*
Plataforma web para gestão de pastorais e escalas litúrgicas do Santuário N. Sra. de Fátima, com coleta de disponibilidade via Magic Link no WhatsApp, escala automática por rodízio e conformidade LGPD para menores.
- **Minha atuação:** modelagem/documentação de domínio, automação de sprints via GitHub API, fundação Angular 22 Standalone/Zoneless responsiva, módulo de autenticação JWT/perfis, fluxos de missas manuais/última hora e CRUD de pastorais com testes Vitest e Playwright E2E.

`Angular 22` `TypeScript 6` `Angular Material M3` `Tailwind CSS v4` `Vitest` `Playwright` `GitHub Actions`

### 🍲 [Ecommerce de Panelas](https://github.com/TRLeandro/Ecommerce_de_Panelas) — Backend B2B
API REST em **Java 25 + Quarkus 3.34** para e-commerce B2B do setor gastronômico, com catálogo granular, endereços normalizados, pedidos, cupons e pagamentos (Cartão, Pix e Boleto).
- **Destaques:** JWT assimétrico, Argon2id, proteção contra IDOR, `@Version` + trava pessimista em cupons, gateway de pagamentos plugável (`Idempotency-Key`, `tokenCartao` efêmero e webhooks HMAC-SHA256), RFC 7807 `ProblemDetail` e **28 classes de teste** (JUnit 5 / REST Assured).

`Java 25` `Quarkus 3.34` `Hibernate / Panache` `PostgreSQL` `Redis` `JWT / Argon2id` `JUnit 5` `REST Assured`
